# เว็บพอร์ตโฟลิโอ / CV ของเอ็ด

หน้าเว็บหน้าเดียว กดแล้วเนื้อหาเลื่อนขึ้นมาเป็น overlay ไม่เปลี่ยนหน้า มีสองภาษา (ไทย/อังกฤษ) และกด "บันทึก CV เป็น PDF" ได้ เนื้อหาทั้งหมดแก้ใน Google Sheets

## ไฟล์ในโฟลเดอร์
- `index.html` หน้าตาเว็บ (ไม่ต้องแก้)
- `app.js` ตัวทำงาน (ไม่ต้องแก้)
- `config.js` ไฟล์เดียวที่ต้องแก้ ใส่รหัส Google Sheet
- `fallback.js` เนื้อหาสำรอง ใช้เมื่อโหลดชีตไม่ได้ หรือยังไม่ได้ตั้งค่าชีต
- `assets/portrait.jpg` รูปโปรไฟล์ (ดึงมาจาก CV เดิม เปลี่ยนไฟล์ชื่อเดิมได้)
- `ed-cv-content.xlsx` (ส่งแยกต่างหาก ไม่อยู่ในโฟลเดอร์นี้) ต้นแบบชีต นำเข้า Google Sheets ไม่ต้องอัปโหลดขึ้น GitHub

## ขั้นที่ 1 ทำชีต (ประมาณ 5 นาที)
1. เปิด Google Sheets → File → Import → Upload เลือก `ed-cv-content.xlsx` → เลือก "Replace spreadsheet"
2. กด Share → General access → "Anyone with the link" สิทธิ์ Viewer
3. คัดลอกรหัสชีตจากแถบที่อยู่ คือส่วนระหว่าง `/d/` กับ `/edit`
4. เปิด `config.js` วางรหัสใน `sheetId: "..."`

อ่านแท็บ "อ่านก่อน" ในชีตสำหรับกติกา (อย่าเปลี่ยนชื่อแท็บและหัวคอลัมน์)

## ขั้นที่ 2 ขึ้น GitHub Pages
1. สร้าง repository ใหม่ (public) อัปโหลดไฟล์ในโฟลเดอร์นี้ทั้งหมด (index.html, app.js, config.js, fallback.js, assets)
2. Settings → Pages → Source: Deploy from a branch → Branch: main, โฟลเดอร์ / (root) → Save
3. รอ 1-2 นาที เว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/ชื่อrepo/`

## แก้เนื้อหาทีหลัง
แก้ในชีตเฉยๆ หน้าเว็บอัปเดตเองภายในไม่กี่นาที ไม่ต้องอัปโหลดอะไรใหม่ (เปลี่ยนเฉพาะรูปหรือ config.js เท่านั้นที่ต้องอัปโหลด)

## เพิ่มผลงาน
แท็บ `works` หนึ่งแถว = หนึ่งชิ้น ช่อง `body_th/body_en` คือเนื้อหาที่เปิดอ่านใน overlay ช่อง `url` คือลิงก์ต้นฉบับ (มีปุ่ม "อ่านต้นฉบับ") แถวตัวอย่าง 3 แถวเป็นข้อความสมมติ ต้องแก้หรือลบก่อนเผยแพร่

## ข้อควรรู้
- ข้อมูลส่วนตัวใน CV เดิม (เงินเดือน วันเกิด น้ำหนัก ส่วนสูง ที่อยู่) ถูกเว้นว่างไว้ เพราะชีตที่แชร์ด้วยลิงก์ใครเจอก็อ่านได้ ใส่เองเมื่อพร้อม และใช้คอลัมน์ `web`/`print` เลือกว่าจะโชว์บนเว็บหรือในไฟล์พิมพ์
- ศาสนาใน CV เดิมเขียนว่า "Thai" (น่าจะพิมพ์พลาด) จึงเว้นว่าง
- ตำแหน่ง "Writer" ของ TEMPO.wev เป็นการเดาจาก CV เดิม ช่วยตรวจ
- ฟอนต์โหลดจาก Google Fonts: Libre Baskerville (ตัวอ่านหลัก), Noto Serif Thai (ไทยแบบมีหัว), IBM Plex Sans Thai (ไทยแบบไม่มีหัว), IBM Plex Mono (ป้ายเล็กๆ) ถ้าออฟไลน์จะใช้ฟอนต์ระบบแทน
- สีและฟอนต์ทั้งหมดอยู่ที่บล็อก `:root { ... }` ต้นไฟล์ `index.html` เปลี่ยนเลขสีตรงนั้นได้เลย (ตอนนี้เป็นโทนขาว/เทา/ดำ)
